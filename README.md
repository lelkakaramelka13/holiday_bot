# Бот "Какой сегодня праздник"

Каждое утро присылает в Telegram список праздников на сегодня.
Источник данных — открытый RSS-фид calend.ru (без блокировок и без
скрейпинга HTML). Работает бесплатно через GitHub Actions — свой
сервер не нужен.

## Настройка (один раз)

### 1. Создать бота в Telegram
1. Напишите **@BotFather** в Telegram → `/newbot` → следуйте инструкциям.
2. Получите **токен бота** (выглядит как `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).

### 2. Узнать chat_id
Куда слать — вам лично, в группу или в канал:
- **Себе лично**: напишите боту `/start`, затем откройте в браузере
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`.
- **В канал**: добавьте бота администратором канала, отправьте туда
  любое сообщение, затем тем же способом посмотрите `getUpdates`
  (id канала будет отрицательным, например `-1001234567890`).

### 3. Выложить код на GitHub
Создайте новый репозиторий и залейте туда содержимое этой папки
(`holiday_bot.py`, `.github/workflows/daily-holiday.yml`).

### 4. Добавить секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
- `TELEGRAM_BOT_TOKEN` — токен бота из шага 1
- `TELEGRAM_CHAT_ID` — id из шага 2

Готово. Бот будет присылать сообщение каждый день в 06:00 по Москве.
Можно поменять время в `daily-holiday.yml` (строка `cron`) или
запустить вручную — вкладка **Actions → Праздник дня в Telegram → Run workflow**.

## Проверить локально (по желанию)
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
export TELEGRAM_CHAT_ID="ваш_chat_id"
python3 holiday_bot.py
```

## Если захочется вернуться к kakoysegodnyaprazdnik.ru
У этого сайта праздники интереснее и их больше (там бывает 40-70 штук
в день, включая шуточные — «День завитушек», «Праздник нелегального
пития» и т.п.), но сайт блокирует автоматические запросы.
Обойти это можно (например, через headless-браузер вроде Playwright,
который имитирует настоящий браузер), но это заметно сложнее и
менее надёжно — такой вариант может сломаться при любом обновлении
защиты сайта. Дайте знать, если захотите такой вариант вместо
calend.ru — соберу отдельно.
